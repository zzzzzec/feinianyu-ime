# 飞念语输入法 0.3.2

- 续写改为按原始概率过滤，提供 0–3 条建议；一条也可显示，低分时完全不展示，不再凑满三条。
- 后续内容分数不足就提前停止，每条最多八个字符，减少越补越远的长句。
- 修复跳过高概率逗号后强选低分词的问题，上句未输入标点的古诗可先补标点再续写。
- 新增“建议强度”：保守（默认）、均衡、宽松。使用原候选栏的外观和点选方式。
- 导出的性能记录增加逐步评分、策略门槛、截断和不显示原因，仍不记录输入及候选原文。
- 模型文件不变，覆盖升级保留下载与已有设置。

十六组古诗小样本对照：原版首选六组接对、十组接错；保守策略十组接对、六组不显示；均衡十二组接对、四组不显示。不显示不计为正确，这些结果不代表整体准确率。
