# 飞念语输入法 0.3.4

- 新增“遥测”设置页：输入与候选采集、续写性能样本、云端同步分别开关，默认关闭。
- 可填写 HTTPS 服务地址，导入设备专属配对文件，测试连接和设备权限；修改地址后重新配对。
- 支持自动同步、立即同步、不计费网络和充电条件，显示待同步条数、大小、最近成功时间和错误。
- 批次持久化、SHA-256 校验和回执确认，断网或重启继续重试；配对凭据加密保存在本机，覆盖升级保留。
- 可记录原始拼音、候选原序与展示序、按键、选词及最终上屏，开启后开始积累。
- 保存真实错拼、光标和部分选词状态，使用会话、决策和动作编号关联候选与提交。
- 词典/Qwen 续写的输入、结果与接受单独记录；剪贴板粘贴单独标记。
- 支持排除应用、暂停、导出 ZIP、导出性能记录和清空本地数据。容量达到上限或写入失败时暂停并提示。
- 密码及禁止个性化学习的输入框不采集，旧编辑框的迟到事件不混入新会话。普通运行日志不再输出输入事件正文。
- 附带离线回放样本构建脚本，区分用户自然选择与人工确认答案。
- 保留已有主题、词库、剪贴板、Qwen 模型和续写性能记录。
