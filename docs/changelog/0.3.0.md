# 飞念语输入法 0.3.0

- 新增 Qwen3.5-0.8B-Base 智能续写：中文上屏后稍作停顿，在键盘候选栏显示短语补全，点击采用。
- 替换原有拼音上屏后的联想；拼音选词、词典、用户学习及 Suzu 排序保留。
- 模型通过 Wi-Fi 独立下载并校验，约 505 MiB；安装应用更新时复用已下载模型。
- 新增“智能续写”设置，可调整前文长度、响应时限，查看模型下载状态及导出性能记录。
- 继续输入、移动光标或切换输入框时取消旧请求；密码等敏感输入框不提供续写。
- 性能记录保留加载、前文处理、生成、候选显示、超时及取消耗时，不记录聊天原文。

本版先完成模拟器功能验证，真机延迟、内存与耗电仍需实测。模型尚未针对个人语料微调，续写请按需要选用。
