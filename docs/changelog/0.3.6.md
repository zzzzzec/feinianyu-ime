# 飞念语输入法 0.3.6

- 复制文字或图片后，进入输入框可在候选栏看到快捷粘贴按钮；图片显示缩略图。
- 文字整段粘贴，保留换行、标点和完整内容，不拆词，不提取电话号码或链接；长文仅缩短按钮预览。
- 拼音候选优先显示，开始输入后收起剪贴板提示；待粘贴内容优先于智能续写，避免被 Qwen 覆盖。
- 成功粘贴后，同一次复制不再反复提示；重新复制同样内容可以再次提示。
- 新默认提示有效期为 2 分钟，已有自选时长保留，可在“剪贴板 → 剪贴板提示超时”调整。
- 修复提示超时后未立即收起、切换输入框遗漏系统剪贴板及异步图片覆盖较新复制内容的问题。
- 保留现有配置、词库、模型、剪贴板历史与遥测配对。
