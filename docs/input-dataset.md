# 输入数据采集

0.3.4 新增独立的本地采集模块。默认关闭，在“遥测 → 记录输入与候选”开启。可暂停、排除已经使用过的应用、导出 ZIP 和清空记录。重启和覆盖升级保留记录；另行导入设备配对并开启云端同步后才会上传，详见[遥测使用](telemetry.md)。

## 记录内容

- 每个编辑框有独立随机会话 ID；事件含时间、应用版本和源码提交。
- 从固定版本拼音引擎的 PinyinState / LibIME PinyinContext 读取原始输入、输入光标、已选择拼音长度和汉字片段。保留错拼与未完成输入，不从答案反推拼音。全拼和双拼记录各自模式；非拼音输入的 raw_input 为 null。
- 每个候选快照保留前 16 项的文本、原序、展示序和可用的 Suzu 分数。Suzu 只改变前 10 项；实际下发界面的候选和后续加载页另记 candidate_page。原候选顺序不可恢复时明确标记 original_order_known=false。候选 ID 在该次快照内稳定。
- 记录按键、修饰键、候选点击、动作处理结果、引擎提交，以及 InputConnection 提交结果。使用会话、决策与动作 ID 关联，采集回调在 Fcitx 线程同步进入有界写入队列，不经过可能丢旧事件的 UI SharedFlow。
- 记录退格、删除和编辑框光标/组合输入范围。编辑动作是观察，不自动解释成“上一候选错误”。
- 输入法剪贴板粘贴标记 paste；编辑面板的系统粘贴记 paste_action。其他应用自身的粘贴不能可靠归因，不作为拼音目标标签。图片文件不进入数据集。
- 智能续写另外保存有限前文、词典/Qwen 结果、展示和接受事件，和拼音转换分开。

密码、非文本、禁止个性化学习以及排除的应用不采集。切换编辑框会使旧会话失效；迟到事件无法写入新会话。没有对应原生事件的引擎上屏只记事件类型和长度，不保存无法归属的文本。普通日志不输出数据集原文。

## 存储与导出

数据库位于 noBackupFilesDir/input-dataset/events.sqlite，独立于剪贴板数据库、词库学习和性能日志。导出 ZIP 含 manifest.json 和 events.jsonl；事件按持久化序号排列。事件正文上限 256 MiB，数据库还有页和索引开销。达到容量上限、队列满或写入失败会暂停采集并显示原因，不自动删除旧数据。清空会使排队的旧写入失效。

导出的文件含原文及应用信息，应保存在自己的数据目录，不提交到公开仓库。系统备份不包含此数据库。

## 构建第一份回放样本

```text
python scripts/build-input-dataset.py export.zip --output-dir ../.private/input-evaluation/run-001
```

输出 observed-choices.jsonl 和 summary.json。只选能关联快照、动作结果和成功上屏的完整拼音决策；保留真实原始输入，要求原序已知，排除部分选择、特殊模式、缺失或歧义候选、失败提交与粘贴。一轮组合输入最多计一个样本。跳过原因计入汇总，完整轨迹仍保留在原始 ZIP。

标签为 observed_behavior_not_human_gold：记录用户接受了什么，不等于用户确认唯一正确答案。候选消耗的精确拼音区间尚不可得，因此 consumed_range=null；不同覆盖范围的候选不能直接用于端到端准确率计算。当前可做冻结候选池的选择拟合与排序回放，不声称完整重现当时的学习词库或双拼配置。人审确认后才能建立质量金标准。

训练和测试按后续日期及会话划分，整轮组合输入保持在同一分区。复制、续写、删改轨迹与拼音选词分别分析，不把一个词的所有输入前缀当成多个独立样本。
