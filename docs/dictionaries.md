# 两种词库

拼音词库负责拼音到词语候选；原文接续库负责已经上屏的文字到确定的后文，两者不互相代替。

## 拼音选词

首次运行时，在 Fcitx 启动之前将内置的四份 THUOCL 派生文本词库转换为 LibIME 二进制词库，原子安装在应用原有外部文件目录的 data/pinyin/dictionaries。仍由原有词库管理页控制启停、删除。安装标记独立于应用版本，用户删除或停用后不会自动补回或启用，不覆盖个人文件及学习记录。直接启动且用户未解锁时跳过安装。IT 词表补充了少量现代 AI 术语；历史人名词表不等于通讯录或全部现代姓名。

## 上屏后接续

FixedCompletionEngine 在 IO 线程只读查询索引。先使用 OpenCC 归一化简繁体并忽略标点，按输入末尾最长 4–24 汉字匹配，提供至下一处句读的原文，最多 3 条、每条最多 32 字。保留句首标点，输入已有标点时去重。词典命中（含已到作品结尾）不调用 Qwen.generate；未命中或词库不可用再走原有 Qwen 流程。候选展示、点击、快照失效及敏感输入框限制复用现有机制。模型未下载时也可使用原文接续。

词库资产使用独立 ID 和 SHA-256；解压并校验后原子安装到 noBackupFilesDir/completion-dictionaries，普通 APK 覆盖升级复用，清除数据或卸载会移除。此版随 APK 提供词库，不新增联网词库更新器；模型下载、模型 ID 与模型缓存不变。

性能导出新增 dictionary 阶段，包括 lookup_ms、命中状态、matched_chars、dictionary_id；展示与采纳记录带 source。词典记录不冒充模型概率，也不保存输入、候选、作者篇名。模型评测结果与检索命中率应分别统计。

## 可复现构建

安装 scripts/dictionaries-requirements.txt 中的固定版本构建依赖，运行 python scripts/build-dictionaries.py。脚本下载并校验 scripts/dictionaries-*-sources.json 中固定提交的源文件；也可用 --poetry-raw 指定已下载的原始诗词目录。输出 assets/dictionaries，构建说明和原许可证随 APK 提供。mobile 索引中的 start 使用 UTF-16 偏移，与 Android 字符串一致。

源数据版本、许可及筛选条件见 assets/dictionaries/NOTICE.md。词库保留源文本的异文，例如李绅诗中的“秋成万颗子”；没有匹配的不同版本不会被伪造成确定原文。

## 本版验证

10 项 JVM 单元测试通过；x86_64 / API 36 模拟器中两项仪器测试通过，覆盖简繁与跨行诗句、完整七言接续、固定成语、四类拼音词库转换与候选、用户删除后不自动补回、原候选栏点选、诗尾停止、命中不调用 Qwen、未命中回退及密码框排除。UI 功能测试使用 10000 ms 预算，结束后恢复原设置；这些检查不代表真机延迟达标。

覆盖安装保留了原有 529297536 字节 Qwen 文件及其修改时间、剪贴板图片文件。测试截图和性能记录单独保存在任务产物中，不随公开源码发布。
