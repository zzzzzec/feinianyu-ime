# 遥测

在输入法设置中打开“遥测”。所有新增采集与同步开关默认关闭。

## 使用

1. 输入与候选采集用于积累拼音、候选和实际选择；续写性能样本单独开启。原有续写性能文件及其导出继续保留。
2. 点击“服务地址”可填写 HTTPS 地址。导入设备专属配对 JSON 文件时会显示目标服务，确认后配对，但不会自动开启上传。
3. 点击“测试连接”核验服务及设备上传权限，再开启“自动同步”。默认只使用不计费网络，可附加仅充电限制。
4. “立即同步”会安排后台任务，同样遵守网络和充电条件。界面显示待同步条数与原始记录大小、最近成功时间和错误。
5. 可随时关闭同步、解除本机配对或导出数据。清空本地会删除本地事件及待传批次，云端已保存的数据保留。

“不计费网络”以 Android 网络标记为准，可能包括 Wi-Fi、以太网等。后台使用与应用更新相同的 Android JobScheduler，周期最短 15 分钟；运行时间由系统决定。新增记录会合并安排一次性任务，不逐按键联网。

## 配对格式

```json
{
  "schema": 1,
  "server_url": "https://your-service.example",
  "device_id": "11111111-1111-4111-8111-111111111111",
  "upload_token": "REPLACE_WITH_A_RANDOM_256_BIT_BASE64URL_TOKEN",
  "access_client_id": "",
  "access_client_secret": ""
}
```

这只是格式示例，不是可用凭据。Worker 端需配置设备 ID 与上传令牌的 SHA-256 并启用该设备。使用 Cloudflare Access 时额外提供该设备的 Client ID/Secret；自托管服务可以将二者留空。管理 token 不写入 APK 或配对文件。配对文件包含上传凭据，应通过个人私有渠道交付，不放入公开 Release、源码或数据集。

配对 JSON 上限 32 KiB。服务地址只接受 HTTPS，不接受 URI 用户信息、查询或片段；不会跟随重定向转发凭据。地址变更时关闭同步并移除旧凭据，输入数据仍保留。凭据用 Android Keystore 密钥加密，密文、采集数据库和上传进度位于 noBackupFilesDir；覆盖升级保留，卸载或换机重新配对。

## 数据与可靠性

数据集 ZIP 始终包含完整本地记录，成功上传不会删除本地事件。正文容量上限为 256 MiB，达到上限会暂停采集，不覆盖未上传记录。新的采集仅从开关打开后开始，不能恢复旧版未保存的输入。

事件按 SQLite 持久化序号封装为 gzip JSONL，每批最多 512 条，并优先控制未压缩大小在 512 KiB 内，压缩文件上限 1 MiB。封存的批次 ID、元数据和字节保存在数据库中；重试不重新生成。事件附带 installation_id、generation 与 record_id，供云端去重排序；清空本地创建新的 generation。

客户端逐项核对服务回执中的设备、代次、批次、序号、数量、字节数和 SHA-256，只有全部匹配才在 SQLite 事务中推进游标并删除封存批次。收不到回执或回执不匹配时不跳过记录。网络中断、进程退出、系统重启后可从持久化批次继续。

## 自定义服务

详见 [接收端与 HTTP 协议](../server/telemetry/README.md)。地址可以包含服务根路径，服务端需将对应路径映射到以下接口：

- GET /v1/device：鉴权后返回 schema=1、当前设备 ID 与 upload capability，不提交采集内容。
- POST /v1/batches/&lt;uuid&gt;：接收 gzip 文件与批次元数据，成功持久化后返回匹配回执。

默认接收端使用私有 R2 binding。其设备凭据只有上传能力，所有者下载与管理使用独立渠道。输入法正常候选与 Qwen 推理继续在本机执行；遥测上传不参与候选生成。
