# 本地语音输入

设置首页 → 语音输入。首次下载模型并允许麦克风，之后在输入框中点击键盘顶栏右侧的麦克风。
语言默认自动识别，支持中英混输，也可指定普通话、粤语、英语、日语或韩语。麦克风长按可进入设置。
完成的语音片段直接写入当前输入框；点麦克风结束录音并处理剩余片段，返回键盘取消尚未完成的识别。

## 接口与生命周期

- `SpeechAudioSource`：16 kHz、单声道 PCM16 录音来源，测试可注入公开音频。
- `SpeechProvider`：独立的模型准备、音频段识别、资源释放接口；`SpeechProviders` 注册服务与本地/远程类型。
- `SenseVoiceProvider`：本地 sherpa-onnx 实现，后台加载与串行解码。
- `SpeechController`：协调录音、VAD、有限队列、识别状态和取消；目前只有本地 provider。
- `SpeechEditorGuard`：绑定输入框代次及选择范围，校验每次写入，丢弃切换输入框或移动光标后的结果。
- `SpeechWindow`：沿用键盘配色、顶部返回与设置入口，显示转写、录音电平和麦克风状态。

当前接口接收完整音频段。未来实时服务应另加流式 session 接口，不能把文件上传 API 当作实时识别。
新增服务只替换 provider；录音、编辑器保护和键盘界面继续使用。

## 当前模型与体验

SenseVoice Small int8（2024-07-17 转换版）配合 Silero VAD，默认自动识别语言，启用逆文本归一化。
VAD 在约 0.7 秒停顿后形成片段，单段最长 12 秒，整次录音最长 120 秒，连续约 10 秒无语音后结束。
这是停顿后分句显示，不是逐字流式。三个待识别片段的队列满时结束并提示分段说话，避免无限积压。
没有开启 LLM 自动润色。去除 SenseVoice 特殊标记后插入；中文段直接连接，连续英文词段之间补空格。

语音期间暂停并卸载 Qwen，返回键盘后按续写设置恢复。ASR 和 VAD 在会话退出后释放。
密码与数字输入框不显示麦克风，有未完成拼音时麦克风禁用。
切换输入框、移动光标、收起键盘、切换主题或离开语音面板会停止录音并废弃迟到结果。

## 下载与更新

APK 含 sherpa-onnx 2.0.1 运行库；构建前运行 `scripts/fetch-speech-runtime.ps1` 下载按 SHA-256 固定的官方 AAR。
用户在设置页首次下载模型。DownloadManager 支持后台下载和进程重启恢复；默认仅 Wi-Fi，可自行调整。
三个文件按固定版本和 SHA-256 分别校验后原子安装，损坏文件不能覆盖已验证的模型。
文件位于 `noBackupFilesDir/speech-models/sensevoice-small-int8-c71f0ce0-vad5`，覆盖升级 APK 时保留。
总下载量 241,357,257 字节（约 230 MiB），不随每次 APK 更新重新下载。

## 日志与验证

设置 → 语音输入 → 导出语音性能记录，导出 JSON。
记录资源交接、模型与 VAD 加载时长、音频长度、推理时长、分句完成到结果的延迟、实时率（推理时长 / 音频长度）、字符数、是否写入及错误类型。
内存指标属于整个输入法进程，不能当作语音模型独占内存。
性能记录不含录音、转写文字和 API Key；本地文件有大小上限。
若已开启输入数据采集，成功写入的文字经原有 `editor_commit` 管线记录，来源为 `speech`，不伪装为拼音候选选择。
录音仅留在内存，不保存音频文件。语音性能记录暂未接入遥测上传。

`SpeechContractsTest` 检查分段连接、特殊标记和编辑器隔离。
`SpeechRecognitionTest` 用实际 Android native runtime 识别上游公开 `zh.wav`，验证 VAD→识别管线、取消后不写入和损坏下载保护。
模型与公开音频由本地测试环境提供，不将大文件或用户录音提交到 Git。
模拟器时间仅用于功能验证；手机速度、口音、噪声与中文准确率仍需真机样例评测。

当前在 API 36 x86_64 模拟器上验证。通过 ARM Native Bridge 加载官方 ARM64 ONNX Runtime 会在初始化阶段崩溃，因此应用会在加载前拦截这种组合并提示使用 x86_64 包。功能测试使用原生 x86_64 包；手机包为 ARM64，尚未完成真机验证。
公开样例 `zh.wav` 的记录同时保存上游示例参考文本和实际输出：目前有“开放 / 开饭”的一字差异，不能据此声称达到 Gboard 的准确率。
