# Qwen 上屏后补全

设置 → 智能续写。应用默认启用，在 Wi-Fi 下下载独立模型；下载完成并校验后离线工作。
前文长度和响应时限可调整，同页可导出性能记录。

## 模型与升级

- 使用 Qwen3.5-0.8B-Base 的 Q4_K_M 文本权重，直接续写，不使用聊天模板、思考模式或视觉模型。
- 原模型：https://huggingface.co/Qwen/Qwen3.5-0.8B-Base
- 量化来源：https://huggingface.co/mradermacher/Qwen3.5-0.8B-Base-GGUF
- 固定 revision：`d98ffedc21f95bcd34909d356dffa47cffcd0066`。
- 文件大小 529,297,536 字节；SHA-256 `99fe51dc14029f8fb69c9c90a8c59ce733488df22a2de09f4e69203bf1e9fd93`。
- 系统 DownloadManager 管理下载，支持应用进程退出后的继续下载；完成后校验大小和 SHA-256，临时文件原子替换为正式文件。
- 正式文件位于 `noBackupFilesDir/completion-models/`，不在 APK、缓存目录或系统备份中。模型 ID 与 APK 版本独立，正常覆盖升级复用文件，不重复下载。清除应用数据或卸载会删除模型。
- 已校验文件通过模型 ID、大小、修改时间确认复用；下载校验失败保留已有正式文件。当前不自动更换模型版本。
- 模型按 Apache-2.0 使用；署名与许可证随 APK 的 `assets/qwen/` 提供。没有训练或微调权重。

## 输入和交互

- 当前支持中文输入模式、当前输入框末尾的上屏文本。只读取光标前最近 128 个 Unicode 字符，可调 32–256；不读取屏幕、其他输入框或聊天对方的消息。
- 有选区、光标右侧有文字、仍有拼音/preedit、密码/数字/电话/禁止个性化学习的输入框，均不生成补全。
- 开机尚未解锁、加密用户数据不可用时不加载或下载 Qwen，原有键盘仍可使用。
- 文本变化后等待 180 ms，再在独立工作线程推理。默认总时限 800 ms，包括等待、排队、读取前文、生成和候选显示；测试可调至 10 秒。
- 贪心解码最多 16 个 token，最多显示 12 个 Unicode 字符，在换行、句末或短语标点停止。先提供一条短续写，点击采用，× 关闭。
- 候选使用现有键盘主题和候选字号。输入拼音时正常显示原有拼音候选。
- 新按键、输入变化、移动光标、选择文本、切换键盘面板、切换输入框或隐藏键盘会取消请求。显示前和采用前再次核对前文、光标和输入框代次。过期/超时结果不展示。
- Fcitx 拼音的 `Prediction` 关闭，配置保存/重载不会重新开启；原来的联想按钮移除。模型缺失、关闭或超时时不回退到旧的上屏后联想。拼音转换、词典、用户学习和现有 Suzu 候选重排保留。

## 推理与性能记录

- 复用仓库固定的 llama.cpp b11632，CPU 两线程；不阻塞 Fcitx 或 Android 主线程。
- 模型在使用期间复用，键盘隐藏后清除上下文，空闲一分钟后释放模型。
- 对相同/追加的 token 前缀复用保存的 prefill 状态。Qwen3.5 含循环状态，不能简单删除任意生成后缀；每次恢复前文快照再续写，前缀变化或窗口截断时重算。
- `noBackupFilesDir/completion-perf.jsonl` 持久保留加载、推理、显示、采用记录；到约 512 KiB 后保留最近一部分。应用覆盖升级保留，可在“智能续写 → 导出性能记录”导出 JSON。
- 记录包括应用版本、模型 ID/哈希、进程会话 ID、请求 ID、设备/架构/模拟器标志、加载、排队、prefill、首 token、后续解码、原生总耗时、可点击候选显示耗时、缓存复用 token 数、超时和取消结果。
- 每条记录带源码提交，汇总脚本只统计本次导出版本对应的提交，避免旧版本数据混入；未触发的请求记录跳过原因。
- 加载和推理后记录进程 RSS/历史峰值及可用的系统热状态；这是整个输入法进程的内存，包含 Fcitx、Suzu、Qwen 和界面，不是 Qwen 权重独占内存。
- 性能日志不保存输入原文、生成文本、应用包名或设备序列号。功能测试使用的通用测试句和结果单独保存在测试输出中，不属于日常性能日志。
- UI 耗时取首次 pre-draw 回调，接近候选显示时刻，尚未计入显示屏扫描输出的延迟。
- 比较时分开看冷加载、无缓存 prefill、缓存复用和最终候选显示。不能用首 token 或 tokens/s 代替可点击短语延迟；同时统计超时和取消，不能只报告成功请求。
- 模拟器数据只验证功能和记录链路；真机需复测默认 800 ms 下的显示比例、p50/p95、超时率、内存、耗电和热降频。当前没有真机成绩。

## 验证入口

- `CompletionTextTest`：Unicode 窗口和输出控制字符处理。
- `QwenCompletionTest`：真实 Base 权重生成、前文缓存隔离、取消、超时、无效模型保护、原有拼音联想关闭。
- `QwenCompletionUiTest`：真实候选绘制和点击上屏，移动光标后旧候选不能上屏，密码框不显示补全。该功能测试放宽模拟器时限，结束后恢复。
- 性能汇总：`python scripts/summarize-completion-perf.py export.json --output summary.json`。

未经个人语料适配的 Base 模型可能给出通顺但偏离意图的续写。例如测试中，表达担心直接上线的前文被续成“先上线，”。候选始终需要点击确认；这些功能检查不代表补全准确率达标。
