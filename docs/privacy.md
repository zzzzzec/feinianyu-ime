# 隐私

飞念语使用编辑框光标前的有限上文，在本机为输入法候选排序。模型不向网络发送上文或候选。
密码、数字、电话与禁止个性化学习的输入框不提供模型上下文。切换输入框和失焦时清除相关缓存。

0.3.4 的“遥测”提供输入与候选采集、续写性能样本和云端同步三个独立开关，默认关闭。开启输入采集后保存普通文本输入框中的原始拼音、有限上文、候选顺序、选词、上屏与编辑事件，供个人建立评测集；支持暂停、排除应用、导出和清空。密码与禁止个性化学习字段不采集，不读取屏幕。剪贴板历史、词库学习和主题仍独立管理。

导入专属配对文件并开启云端同步后，已采集记录将按所选网络和充电条件通过 HTTPS 上传到配置的服务地址，默认服务使用 Cloudflare Worker 和私有 R2。服务地址可自行修改，修改后移除本机旧凭据并关闭同步。手机只持有设备上传凭据，使用 Android Keystore 中的 AES-GCM 密钥加密保存，日志和导出数据集不包含凭据。服务端按设备目录保存批次，不公开桶，上传接口不提供数据下载。清空本地不会删除已上传的云端数据。详见 [遥测使用与协议](telemetry.md) 和 [采集与回放](input-dataset.md)。

应用更新只向 GitHub 请求 Release 元数据和 APK，不携带个人输入、剪贴板或词库。
Android 系统备份按设备设置执行；采集数据库、上传进度、加密配对凭据、模型和升级前配置快照位于 noBackupFilesDir，不纳入系统备份。遥测开关也排除出系统备份和设备迁移，卸载重装或换手机需重新配对；正常覆盖升级保留。
