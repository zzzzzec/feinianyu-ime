# Gboard 浅色外观：第一阶段配置

后续 Suzu 集成版已内置同名浅色主题及默认布局，新安装无需导入；键盘和候选字号可在“虚拟键盘”设置中调整。下面保留第一阶段配置包的用法，供旧版或手动恢复使用。

通过现有主题格式和设置项接近 Gboard 浅色键盘。配色取自本次模拟器中的 Gboard 15.1.08；APK 源码和构建产物沿用原版本。

## 应用主题

在 Fcitx5 的“主题”页面导入 `GboardStage1Light.zip`，然后在“配置”页把“浅色主题”选择为导入的主题。保持原有的跟随系统深浅色设置；本预设只替换浅色主题。

ZIP 内是上游主题格式 2.1 的 `GboardStage1Light.json`。背景为 `#EEEDF4`，字母键为白色，功能键为 `#DDE2F9`，文字为 `#1A1B21`，没有背景图片。

## 调整设置

完整设置键和值见 `settings.json`。除配色主题外，以下设置沿用 Fcitx5 自带界面：

| 页面 | 设置 | 值 |
|---|---|---|
| 主题 → 配置 | 按键边框 | 开启 |
| 主题 → 配置 | 边框描边 | 关闭 |
| 主题 → 配置 | 圆角半径 | 8 dp |
| 主题 → 配置 | 按键水平间距，竖屏 | 3 dp |
| 主题 → 配置 | 按键垂直间距，竖屏 | 6 dp |
| 主题 → 配置 | 按键符号位置 | 右上角 |
| 主题 → 配置 | 按键涟漪效果 | 开启 |
| 虚拟键盘 | 键盘高度，竖屏 | 26% |
| 虚拟键盘 | 键盘侧边距，竖屏 | 2 dp |
| 虚拟键盘 | 默认展开工具栏 | 开启 |

`settings.json` 是设置清单，不是应用支持的一键导入文件。按键边框开关控制独立按键底色，关闭描边并使用透明阴影即可得到无描边的白色按键。

工具栏图标和顺序、功能键的单独形状、字母及键盘候选栏字号、各行角标的独立显示、空格键语言标签均由现有代码决定。本阶段保留这些行为。横屏尺寸和深色配色保持原设置。

## 验证

Android 16 / 1080×2400 模拟器中检查了空闲键盘、展开工具栏、`nihao` 候选栏和点击“你好”上屏。原配置和运行截图保存在仓库外的工作目录中。
