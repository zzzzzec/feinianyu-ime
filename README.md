# 飞念语输入法 · Feinianyu IME

基于 Fcitx5 Android 的中文输入法，使用 Suzu 重排拼音候选，并支持 Qwen 上屏后短语补全。

[下载 APK](https://github.com/zzzzzec/feinianyu-ime/releases/latest) · [中文更新记录](docs/changelog/0.3.1.md) · [智能续写](docs/qwen-completion.md) · [模型与字体设置](docs/suzu.md) · [更新机制](docs/updates.md)

## 当前功能

- 中文拼音、英文、数字、符号、剪贴板历史和文本编辑，保留 Fcitx5 原有输入能力。
- 内置约 44 MB 的 Suzu-2.4 Q8_0。模型在本机运行，只重排已有候选，不生成新候选。
- Qwen3.5-0.8B-Base 根据已上屏前文生成 3 条短续写，使用原有候选栏和展开面板，替换原有拼音联想。模型独立下载，覆盖升级后复用；性能记录可导出。
- Gboard 风格浅色主题；键盘字体和候选字体可分别调整。
- 从本仓库 Release 自动检查和下载更新，更新页面显示中文 changelog；安装由 Android 系统确认。
- 固定包名 `dev.feinianyu.ime`，同一签名覆盖升级；配置按版本迁移，并在修改前保留快照。
- “排序诊断”可查看候选原序、模型分数、最终顺序与跳过原因，并导出 JSON 日志。
- 剪贴板支持文字和图片瀑布流混排，图片铺满卡片、长按查看完整图片，以及固定、删除、撤销和分享。

个人训练数据采集、屏幕上下文、个性化训练仍属于后续计划，尚未实现。

## 查看与导出排序日志

打开应用首页 → **排序诊断** → 打开 **记录排序结果**，在页面内或其他应用中用拼音输入，再返回选择记录。
页面显示候选原序与最终顺序、每项模型分数和原序惩罚、首选保护、耗时、超时或跳过原因。
**导出 JSON** 可保存全部最近记录，方便分享分析；底部 **实时日志** 保留原有运行日志与文本导出功能。

诊断默认关闭，仅在输入引擎内存中临时保存最近 50 次，重启引擎后清空。
关闭记录会停止新增，已有记录仍可导出或手动清空。记录包含输入上文（最多 30 字）和候选词，请按需开启和分享。
密码、数字/电话输入与禁止个性化学习的输入框不记录文本。诊断文本不写入 Logcat，也不自动上传。

## 安装与设置

手机通常使用 Release 中的 `arm64-v8a.apk`；`x86_64.apk` 供模拟器使用。
首次安装后按应用引导启用输入法，并在输入法列表中添加“拼音”。

### 导入拼音词库

入口为 **输入法 → 拼音右侧齿轮 → 管理词库 → 右下角＋**。
支持搜狗 `.scel`、LibIME `.dict` 和 LibIME 文本格式 `.txt`，导入后勾选启用。
基础中文词库已内置；词库管理页没有条目时，表示尚未安装附加词库。
文本词库需包含词语及对应拼音，纯词语列表需要先转换格式。

### 键盘与更新

“虚拟键盘”页面可调整：

- **Suzu 候选排序**：默认开启。
- **键盘字体大小**：12–32 dp，默认 20。
- **键盘候选字体大小**：12–32 sp，默认 18。

“应用更新”页面可查看中文更新说明、手动检查和安装已下载的版本。
自动下载默认使用 Wi-Fi，每 12 小时检查一次，实际后台执行时间由 Android 调度。
第一次应用内更新需要允许飞念语安装应用；之后仍需在系统安装界面确认。

这是独立应用包，与上游 Fcitx5 的数据目录分开。后续版本覆盖安装本应用会保留其数据；不要卸载后重装。

### 图片剪贴板

在其他应用复制图片后，打开键盘工具栏的剪贴板，可看到图片缩略图。
图片以原始文件保存，替换系统剪贴板后仍可从历史使用；重复内容会合并。
支持图片输入的应用中，点缩略图即可插入。其他输入框会提示复制图片后长按粘贴，或从长按菜单分享。
长按图片可查看完整图片（长图支持上下滚动）、固定、取消固定、复制、分享和删除；删除后可撤销。
历史条数限制同样适用于图片，固定条目保留。单张图片最大 32 MB，敏感图片跟随现有遮盖设置。
用户数据导出/导入包含图片文件，升级保留已有文字历史。

### 自动保存截图

在 **剪贴板 → 自动保存新截图** 开启，并在系统提示中允许访问所有照片。
截图后会自动进入飞念语剪贴板历史；只处理开启后新生成的截图，不批量导入旧相册。
Android 14 及以上若仅允许“选定照片”，无法读取之后的新截图，可从“照片访问权限”进入系统设置调整。
输入法进程被系统暂停时，下次打开键盘会检查遗漏的最近截图。截图文件写入完成后才会保存，并沿用图片去重和历史条数限制。
可识别常见 Screenshots、截图、截屏目录；截图目录和保存方式仍需在具体手机上验证。

## 构建

工具链版本见 `toolchain-versions.json` 与上游 [构建说明](old.md)。

```powershell
git clone --recurse-submodules https://github.com/zzzzzec/feinianyu-ime.git
cd feinianyu-ime
./scripts/fetch-suzu.ps1
./gradlew.bat :app:assembleDebug -PbuildABI=arm64-v8a
```

首次个人发行前运行 `scripts/init-signing.ps1`，并私下备份 `.private/` 的签名文件。
发行签名不进入 Git；没有个人签名配置时，开发包使用 `.debug` 包名，避免与正式使用的数据目录混用。
模型固定版本下载并校验 SHA-256，不提交大权重到 Git；APK 内已包含模型，无需安装后下载。
